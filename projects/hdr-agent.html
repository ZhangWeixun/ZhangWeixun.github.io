HDR Agent: AI Agent for Expert-Guided SDR-to-HDR Optimization

Alibaba Digital Media & Entertainment Group (Youku) | AI Agent / HDR Optimization | 2026

Overview

Designed and built a domain-specific AI agent for SDR-to-HDR remastering. The agent converts expert colorist feedback into structured tuning knowledge, analyzes SDR / Model-generated HDR / manually graded HDR clips, and recommends parameter-adjustment strategies under rule-based governance.

The system connects expert correction records, video feature extraction, diagnostic tools, subjective evaluation reports, and HDR algorithm knowledge into a closed-loop optimization workflow for production HDR remastering.

Agent Workflow

01

Knowledge Intake

Reads expert correction records from DingTalk/MCP knowledge sources and normalizes free-text colorist feedback into reusable problem/action schemas.

02

Media Preparation

Organizes OSS media assets across SDR originals, AI-generated HDR clips, manually graded HDR clips, scene boundaries, face metadata, and CDL exports.

03

Feature Extraction

Runs Python and FFmpeg-based pipelines to extract brightness, contrast, face, color, saturation, gamut, and temporal stability features.

04

Diagnosis

Maps objective signals and expert feedback to HDR issues such as over-bright faces, black-level lift, excessive saturation, gamut shift, or temporal flicker.

05

Parameter Strategy

Recommends adjustment directions for color type, tone control points, HDR white level, SDR highest nit, smoothing, and custom FFmpeg filter parameters.

06

Review & Governance

Uses HTML/JS comparison reports and rule-based checks to keep agent decisions auditable before knowledge is reused downstream.

Feature Extraction Pipeline

Built a Python feature pipeline around the SDR / AI HDR / manually graded HDR triplet. Absolute feature modules describe each clip, while perceptual difference signals explain what the expert correction changed.

F-Series Absolute Features

  • Global brightness, contrast, HDR peak, and tone-control points.
  • Face detection, face brightness, skin-related statistics, and foreground contrast.
  • SDR alignment, gamut extension, saturation amplification, display characteristics, and scene smoothness.

D-Series Difference Signals

  • Zone brightness across dark, mid, gain, and specular ranges.
  • Black level, color temperature, hue, saturation, skin, contrast, and gamut shifts.
  • Temporal stability signals for detecting flicker and scene-level inconsistency.
Modeling frame: X = [F(SDR) | F(AI HDR) | F(AI HDR) - F(SDR) | color_type] Y = F(Manual HDR) - F(AI HDR)

Human-in-the-Loop Knowledge Workflow

  • Developed workflows that transform free-text expert corrections into structured problem/action schemas for downstream learning and evaluation.
  • Linked colorist comments, CDL exports, clip metadata, and feature signals so agent recommendations remain traceable to expert judgement.
  • Built subjective evaluation tooling for ranking HDR variants, aggregating reviewer preference data, and generating HTML analysis reports.
  • Separated experimental diagnostics from production-oriented feature pipelines, allowing targeted tools such as flicker detection to mature independently.
